# Python and Django Sample Programs

## About This Repository

This repository contains basic Python programs and Django examples developed for learning, practice
## Technologies Used

- **Python** – Programming language
- **Django** – Python web framework
- **HTML** – Web page structure
- **SQLite** – Database for Django examples
- **Postman** – API testing
### Run a Python Program

```bash
python filename.py
```

Replace `filename.py` with the Python file you want to execute.

### Set Up Django

Install Django using pip:

```bash
pip install django
```

Check the installed version:

```bash
python -m django --version
```

### Run the Development Server

```bash
python manage.py migrate
python manage.py runserver
```
